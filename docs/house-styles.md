# Projects to borrow from

Briefs for Builder projects name earlier ones: "3D in the perspective of Mage Tower Battle and in the style of Protection of the Spheres", "use buildings from CHUMWORLD", "grass using some tech from Extremely Lifelike Fishing", "2D in Lowballer style". An agent can follow such a line only when it can open the project it names. This page lists the published projects that briefs have pointed at, with what each has been borrowed for, so a reference in `BRIEF.md`'s References section has a known target.

Each one is a public repository and a page. A reference is read, not copied wholesale: code comes in under its licence, and art only with its owner's say ([`LICENSES.md`](../template/LICENSES.md)). Peter's repositories carry no licence yet, so his ideas are rewritten, not copied, and credited. The opening entry says what was taken from each reference; `journal_check.py` fails until it names every one.
