How I read Builder, and how I will build the counter

What Builder asks of me

The one rule here, that the count stays between 0 and the maximum and moves by the step, lives in crates/core/src/counter.rs and is tested there with values worked out by hand. The shim passes values and decides nothing. The page draws the view the core returns, including whether Add and Remove are enabled, and holds no number of its own. The brief approves the plan in advance, so I build without stopping and the person's gate is using the page; I may not push or deploy.

What this project adds or changes

Nothing in BUILDER-SPEC.md's change table, and no kit. The maximum and the step are presentation of the brief's choice, read from data/counter.json and checked by the core.

Measured before any edit

The copied template passes its own ./scripts/check.sh; the reference repository runs that check on every commit.
