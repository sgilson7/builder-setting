Twelve dots, three ways

Twelve dots regroup three ways and the total stays the same.

This animation in the Code scenes deck

What it shows

The same twelve dots regroup as 3 rows of 4, 2 rows of 6 and 1 row of 12, so the total stays 12.

Every step

  1. Twelve dots, in 3 rows of 4.
  2. The same dots move into 2 rows of 6.
  3. And into 1 row of 12: each arrangement still holds 12.
