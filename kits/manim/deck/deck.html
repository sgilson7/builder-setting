Manim kit sample animations

The kit's two sample animations as a slide deck: a scene file of boxes and lines, and a code scene.

  1. Scene files: 1 animations
  2. Code scenes: 1 animations

Use the bar at the bottom, or the arrow keys, to move between slides; the theme picker there switches every animation between light and dark. With reduced motion turned on in your system settings, each animation shows its steps as still frames.

Each animation also has a page of its own, listed on the home page.
